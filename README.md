# Calculadora Soldador

Calculadora web para apoyo a soldadores. Ayuda a calcular la cantidad de barrotes necesarios o el espacio entre ellos para un claro determinado.

## Descripción

Esta herramienta te permite:

- **Calcular cantidad de barrotes**: Ingresa el espacio deseado entre barrotes y obtén cuántos necesitas
- **Calcular espacio entre barrotes**: Ingresa la cantidad de barrotes y obtén el espacio real entre ellos

## Cómo usar

1. Selecciona el **tipo de cálculo** en el menú desplegable:
   - Cantidad de barrotes
   - Espacio de claro

2. Ingresa las medidas en centímetros (cm):
   - **Largo del claro**: longitud total del espacio a cubrir
   - **Ancho de barrote**: grosor de cada barrote
   - **Tercer valor**: varía según la opción seleccionada

3. Presiona el botón **Calcular** para ver los resultados

4. Usa **Borrar todo** para limpiar los campos

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)

## Uso

Simplemente abre el archivo `calculadora.html` en cualquier navegador web. No requiere servidor ni conexión a internet.
